# Boxy

[English](README.md) · **Русский**

Приложение с открытым исходным кодом для управления модулем [Box for Root](https://github.com/taamarin/box_for_magisk)
(Magisk / KernelSU / APatch) на Android. Дизайн повторяет BFR от boxproxy, код написан с нуля на Kotlin и Jetpack Compose.

Языки: English, Русский, Українська, Беларуская, Қазақша, Deutsch, Español, Français, Italiano, Türkçe, 中文, 日本語.

## Возможности

**Главная**
- Статус сервиса с кнопками «Старт» / «Стоп» / «Перезапуск», время работы, сведения о сервисе (PID, версия ядра, память, CPU, привязка к CPU) и перезагрузка конфигурации
- Смена ядра, сетевого режима и IPv6, пока сервис остановлен
- Быстрый переход к панели и журналу, ярлык SubStore, если установлен модуль `sub_store`
- Задержка до трёх настраиваемых адресов
- Карточка IP (локальный или внешний с флагом страны), подробности о внешних IPv4/IPv6
- Скорость с живым графиком (счётчики сети или Clash API, фильтр типов соединений)
- Расход подписки (адреса подписок, proxy-providers или API ядра)
- Карточка «Система» с загрузкой CPU и памятью ядра, системное окружение (ядро Linux, память, IPSet)
- Редактор главной: скрытие разделов, порядок и скрытие карточек

**Приложения**
- Режим проксирования по чёрному / белому списку (`package.list.cfg`)
- Все пользователи Android: основной, второе пространство, рабочий профиль, клоны приложений
- Поиск, сортировка, фильтры (системные / пользовательские, доступ к сети, пользователи), выбрать всё, инвертировать, умный выбор

**Утилиты**
- Конфигурация: выбор активной конфигурации текущего ядра, файловый менеджер для `/data/adb/box`
  (поиск, создание, переименование, удаление, загрузка по ссылке) и редактор кода с подсветкой и поиском
- Управление сетью: правила Wi‑Fi, списки SSID / BSSID с поиском сетей поблизости,
  включение и выключение прокси для клиентов точки доступа, фильтр клиентов точки доступа по MAC
- Обновление: ядра (Mihomo, Sing-box, Xray, V2Ray, Hysteria), подписка, веб-интерфейс с выводом в реальном времени
- Настройки подписки: адреса, файлы провайдеров, интервал, crontab
- Журнал: файлы журналов модуля с автообновлением и цветовой подсветкой

**Панель**
- Веб-интерфейс ядра (Zashboard или MetaCubeXD, можно переключать), свои панели, SubStore, очистка кэша

**Настройки**
- Тема (светлая, тёмная, как в системе, Material You), чисто чёрный фон, выбор языка с флагами
- Панель навигации «жидкое стекло» с размытием фона и линзой, размытие шторок, масштаб интерфейса, системные панели
- Навигация: «Приложения» или «Журнал» четвёртой вкладкой
- Зеркало GitHub для всех загрузок (включая скрипты модуля)
- Уведомление о статусе с кнопками, плитка в быстрых настройках, открытие панели при запуске
- Резервное копирование и восстановление файлов модуля и настроек приложения
- Обновление приложения (релизы GitHub) и модуля (`updateJson`)

## Модуль

В папке `module/` лежит модуль Box for Root для Boxy: оригинальный v1.10.2 с исправлениями, русский установщик,
совпадение Wi‑Fi по MAC роутера (BSSID) и фильтр клиентов точки доступа по MAC. Подробнее в [module/README.md](module/README.md).

Модуль ставится поверх оригинального модуля taamarin как обновление. Установщик сохраняет значения `settings.ini`,
конфигурации, ядра и списки приложений. На вопрос «Восстановить settings.ini?» нажмите «Громкость +» или подождите 10 секунд:
«Громкость −» сбрасывает настройки на значения по умолчанию.

## Сборка

Нужны Android Studio (JDK 17+) и Android SDK 37.

```
./gradlew assembleDebug
./gradlew assembleRelease
```

Подпись релиза берётся из `keystore.properties` в корне проекта (не хранится в репозитории):

```
storeFile=keystore/boxy-release.jks
storePassword=...
keyAlias=boxy
keyPassword=...
```

Без этого файла релизная сборка подписывается отладочным ключом.
